Third Eye Visual Refresh
Design proposal · Sasha's Third Eye v9.18

A visual refresh for the QA & production dashboard

The app is useful but looks text-only. It has no logo or favicon, three icons in total, 46 hard-coded colors and no dark mode. These suggestions keep the navy and teal identity. They add a mark, a consistent icon set and a few charts where tables carry trends today.

01 · Brand mark

Logo & favicon concepts

The name is the idea: an eye that watches quality. Each concept is a flat two-color SVG, so it can be inlined in index.html as the header mark and the favicon with no network request. That matters for a tool that handles PHI offline.

Concept A at real sizes

The app tile keeps the eye legible at 16 px. On the tile, the progress ring on the iris simplifies to a solid teal disc.

    02 · Iconography
    
One icon set, mapped to every control

    
Every icon is drawn on a 24 px grid with a 1.75 stroke, round caps and currentColor, matching the style of the open-source Lucide set (ISC license). Severity icons take the existing good / warn / bad colors, so a fatal error reads at a glance. Click any icon to copy its inline SVG. The monospace line under each label gives the closest Lucide name.

  

  







  

    03 · Layout
    
Header, tabs and Agent Quality, redrawn

    
The header moves from a centered title to a compact left-aligned bar with the mark. The six report tabs get icons and an underline state. The 14-control filter bar collapses into chips with a "More filters" overflow. KPI tiles get an icon chip colored by severity and a period-over-period delta.

    04 · Color
    
Fewer colors, a dark mode, and AA contrast

    
Keep the existing navy and teal. Fold the 46 literal hex values (#3D5470, #2A3F58, #5A7089 and others) into one set of tokens, and add a dark set under prefers-color-scheme. Two current pairs fail WCAG AA for small text, so darken them as shown.

    05 · Type
    
Six sizes instead of nine

    
The CSS uses 10, 10.5, 11, 11.5, 12, 12.5, 13 and 14 px, and card titles look the same as section titles. A fixed scale gives sections, cards and labels three distinct levels. The system font stack can stay, since the app runs offline. If a web font is allowed, IBM Plex Sans and Plex Mono (shown here) keep tabular figures aligned in the score tables.

    06 · Charts
    
Show trends as charts, keep tables for detail

    
The Pareto is the only chart in the app today. These four sections carry trends or shapes that a table hides. Each chart is a small hand-built SVG in the same style as the existing paretoChartSVG, so no chart library is needed. All figures below are examples.
